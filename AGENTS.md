# Mada Finishing project guidance

- Read the requirements and technical design in docs/ before implementing a feature.
- Ask the supervisor before choosing an unapproved architecture, dependency, or code organization convention.
- Keep changes within the agreed feature. Record any missing business requirement and the fictional client decision made for it.
- Keep MVC request handling, inquiry rules, and persistence responsibilities clear within the approved web project.
- Use MSTest for approved automated tests. For the first example of each test type, explain Arrange–Act–Assert and how to run it.
- Report which checks ran, their results, and any behavior still to verify. Ask before pushing or deploying.
