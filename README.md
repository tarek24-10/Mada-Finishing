# Mada Finishing

An Arabic staff dashboard for a fictional finishing company in Mansoura. Noor manages inquiries from a shared inbox. Her coordinators record customer follow-up. The first release was accepted for local Windows use.

## Follow the project

1. **Agree on the work (steps 1–4).** Read the [brief, requirements and acceptance examples](MadaFinishing.Web/docs/Mada_Finishing_01_Discovery_and_Requirements.md).
2. **Build in milestones (steps 5–8).** Use the [backlog](MadaFinishing.Web/docs/BACKLOG.md) for order and status, the [design](MadaFinishing.Web/docs/Mada_Finishing_02_Technical_Design_Draft.md) for implementation decisions, and the [developer README](MadaFinishing.Web/README.md) for setup and tests.
3. **Deliver and support (steps 9–12).** Use the [local handover](MadaFinishing.Web/docs/LOCAL_HANDOVER.md) for release evidence and operator instructions.
